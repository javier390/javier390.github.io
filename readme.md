# 🚀 Personal Portfolio - Javier Avila

Welcome to my portfolio! This project is a showcase of my work as a **Web Developer**, featuring my technical expertise, the projects I've built, and the technologies I master.

![Portfolio Preview](public/img/ann.webp)

## 🛠️ Technologies Used

This portfolio was built using modern frontend technologies to ensure speed and a smooth user experience:

- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, including responsive design and visual effects.
- **JavaScript (Vanilla):** Interaction logic, dark mode management, and animations.
- **FontAwesome:** Professional iconography.
- **Canvas API:** For the "Matrix" style dynamic background effect.

## ✨ Key Features

- **Matrix Effect:** A dynamic and interactive background using the `<canvas>` element.
- **Dark Mode:** Theme toggling for better visual comfort.
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Timeline:** A detailed professional experience section organized by year.
- **Projects Section:** An interactive gallery with direct links to demos and repositories.

## 📂 Project Structure


## 🚀 Installation and Local Usage

To clone this project and run it on your local machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the directory:**
   ```bash
   cd repo-name
   ```
3. **Open `index.html`:**
   You can open it directly in your browser or use an extension like *Live Server* in VS Code.
